Practice Project
================

This is a small Python practice project with a few utilities, a CLI, and tests.

Quickstart
---------

- Create a virtualenv and install dependencies:

```bash
python -m venv .venv
.\.venv\Scripts\activate    # on Windows
pip install -r requirements.txt
```

- Run tests:

```bash
pytest -q
```

Usage
-----

Run the CLI:

```bash
python -m practice_project add 2 3
python -m practice_project fib 10
```
